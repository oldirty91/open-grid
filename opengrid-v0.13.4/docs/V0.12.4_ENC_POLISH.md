# OpenGrid v0.12.4 ENC polish

## Stable rendering

The map keeps previously loaded ENC features in a bounded per-layer cache. New viewport queries are merged into that cache, so a pan or zoom no longer clears the map while replacement data is loading. Queries use a padded viewport to prefetch nearby features.

## Automatic scale selection

When `automatic_scale` is enabled, the NOAA ENC plugin discovers overview, general, coastal, approach, and harbour services. Each dataset is registered with a zoom range and MapLibre selects the appropriate usage automatically. The custom service URL remains available when automatic selection is disabled.

## Hiding classes

Selecting an ENC feature opens the inspector. **Hide this class** adds its S-57 class name to `disabled_classes`, removes every registered scale of that class immediately, and keeps the setting in NOAA ENC plugin configuration for later restoration.
