# Map layers

The old NOAA raster chart overlay has been removed. OpenGrid now uses:

1. The normal dark basemap.
2. An optional **Aerial Imagery** basemap artifact using Esri World Imagery.
3. Data-driven plugin layers, beginning with NOAA ENC.
4. Operational entities, tracks, tasks, and camera geometry above those layers.

Use the **Map Layers** control at the upper right of the map to toggle imagery
and individual plugin layers. Preferences are stored in browser local storage.
