# OpenGrid v0.12.3 fixes

## MAVLink configuration

The MAVLink adapter now publishes a complete JSON configuration schema. The Plugins page renders connection type, TCP, UDP, serial, timeout, source-system, and altitude fields as an editable form. Advanced JSON remains available.

## AISStream

The AIS adapter trims API keys and URLs, sends the subscription within the AISStream three-second requirement, normalizes MMSI filters as strings, records connection/authentication state, and exposes the last connection error and timestamps through plugin metrics. The first received AIS frame marks authentication successful because AISStream does not provide a separate success acknowledgement.

## ENC discovery filters

Primitive array settings are edited as one value per line. Clearing the text area now saves an empty array, allowing Discovery name filters to be removed completely.

## ENC symbol colors

Point presentation now maps S-57 `COLOUR` values to display colors. Common mappings include red (3), green (4), blue (5), yellow (6), black (2), and white (1).
