# ENC interaction

NOAA ENC is a plugin-owned GIS data source. All discovered supported feature layers are displayed by default. Operators can hide individual layers from **Plugins → NOAA ENC → Configuration**. The map intentionally has no separate layer-manager panel.

Point features use compact nautical symbols, while line and polygon features retain their native geometry. Selecting any rendered ENC feature opens the standard right-side inspector with the source layer, NOAA attributes, and geometry.

Aerial imagery is a `MAP_OVERLAY` Artifact and is enabled or disabled from the Artifacts page.
